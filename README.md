# Writer's Box

Local-first version control for writers: GitHub-style history, drafts and side-by-side changes for LaTeX, Markdown, Word, Google Docs, Excel and Google Sheets. Everything runs in the browser, and files never leave the device.

- **Live prototype:** https://claude.ai/artifact/XfYykGFo9fWwGnRe2vCqtx
- **Product spec & MVP plan:** https://claude.ai/artifact/TXbSgAiu4wPqsBacvkoUTx (summary in `docs/overview.md`)

## Run it

Open `index.html` in a browser. It's one self-contained page with no server and no install. It opens on an example project (a policy memo with LaTeX, Word, Markdown, BibTeX and Excel files) so you can try every feature right away.

In VS Code, the Live Server extension (right-click `index.html` › **Open with Live Server**) reloads the page after every build.

## Project layout

```
writers-box/
├── index.html          ← the built app (generated by build.sh; don't edit by hand)
├── build.sh            ← cat src/head.html src/engine.js src/ui.js > index.html
├── src/
│   ├── head.html       ← page shell + all CSS (GitHub-style tokens, light & dark)
│   ├── engine.js       ← zip read/write, Word adapter, Myers diff, IndexedDB storage, version model
│   └── ui.js           ← icons, format adapters (HTML/ODT/Excel/CSV/ODS), views, import/export, example project
├── tests/
│   ├── test_app.py     ← headless browser tests (15 checks)
│   └── screenshots/    ← written by the tests (git-ignored)
└── docs/overview.md    ← decisions, vocabulary, roadmap
```

Edit files in `src/`, then run `./build.sh` in VS Code's terminal (Ctrl+`) to rebuild `index.html`.

## Test it

```bash
pip install playwright openpyxl
python -m playwright install chromium
./build.sh && python3 tests/test_app.py
```

The tests cover the diff engine, Google Docs rich paste, Word round-trips (including tracked changes), ODT, Overleaf zips (folders kept, images skipped), CSV quoting, Excel import (formulas and dates) and re-export, saving versions, and merging drafts.

## How it works

| Concept | Like Git's | What it is |
| --- | --- | --- |
| Project | repository | a folder of related files |
| Version | commit | a saved state of the whole project, content-addressed (SHA-256) |
| Draft | branch | a parallel line of versions; `main` is the default |
| Milestone | tag | a named version, e.g. "Sent to reviewers" |
| Compare | diff | line → paragraph → row, then word-level highlights |

**Formats:** each format has an adapter that turns the file into comparable text and keeps the original bytes.
- LaTeX, Markdown and text are compared line by line.
- Word (.docx) is compared paragraph by paragraph.
- Spreadsheets (.xlsx, .csv, .ods) are compared row by row, cell by cell, with formulas kept.
- Google Docs come in through a rich paste (headings, bold, italics, lists and links become Markdown) or a .docx download.
- Google Sheets come in through an .xlsx/.csv download or pasted cells.

**Storage:** IndexedDB in the browser. Use **Export backup** to save a `.writersbox.json` with every version, draft and milestone, and **Settings › Restore a backup** to load it anywhere.

## Known limits (prototype)

- Word formatting and spreadsheet formatting and charts aren't compared. The original file is kept until you edit it in Writer's Box.
- Merging a draft when `main` has also changed takes the draft's text; three-way merge is planned.
- Importing directly from Google Drive needs the Google Drive connector, which is planned next.
